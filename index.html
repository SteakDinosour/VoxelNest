簡介

VoxelNest（方塊巢穴）是一個桌面啟動器，用來快速開啟 Eaglercraft 網頁版的 Minecraft。它不需要下載遊戲，只要選好版本、按下按鈕，就會在瀏覽器中開啟對應的遊戲頁面。

主要功能：版本選擇、收藏、遊玩紀錄、伺服器清單、四種主題色、設定匯出與匯入。

快速開始

  1. 確認已安裝 Python 3.10 以上，或直接使用打包好的 VoxelNest.exe。
  2. 執行 python voxelnest.py，或雙擊 VoxelNest.exe。
  3. 點左側「▶ 遊戲」，單擊版本卡片選取，再按「▶ 啟動遊戲」。
  4. 瀏覽器會自動開啟 Eaglercraft 頁面。

提示：雙擊版本卡片可以直接啟動，不需要先選取。

遊戲頁

版本卡片

  • 單擊：選取版本（會出現綠色外框）。
  • 雙擊：直接啟動該版本。
  • 右上角星號：收藏或取消收藏。

搜尋與排序

  • 上方搜尋框可輸入版本名稱即時篩選，例如輸入 1.8。
  • 排序選單提供三種模式：
    • 預設：依原始順序。
    • 名稱：依英文字母與數字排序。
    • 收藏優先：收藏的版本排在最前面。

收藏功能

收藏可以在三個地方操作，效果相同：

  • 遊戲頁版本卡片右上角的 ☆ / ★。
  • 遊戲頁底部的「☆ 收藏」按鈕（針對目前選取的版本）。
  • 首頁的「★ 收藏版本」列表會即時顯示你收藏的內容。

收藏資料會保存在設定檔中，下次開啟仍然存在。

伺服器頁

管理伺服器

  1. 在右側輸入名稱（可省略，會以位址代替）與位址（IP 或網域）。
  2. 按「新增」加入清單。
  3. 在左側清單點選項目，表單會自動帶入內容，可以用「更新」或「刪除」修改。

常用標記

選取伺服器後按「★ 設為 / 取消常用」，該伺服器會排在清單最前面。

連線到伺服器

注意：目前無法確認 Eaglercraft 是否支援用網址直接帶入伺服器，因此連線方式是：

  1. 按「連線到此伺服器」，位址會自動複製到剪貼簿。
  2. 遊戲頁面會在瀏覽器中開啟，使用目前選取的版本。
  3. 進入遊戲後，到多人遊戲選單，貼上位址即可。

主題色

打包成 exe

在 voxelnest.py 所在資料夾開啟命令提示字元，執行：

python -m pip install --upgrade pyinstaller
python -m PyInstaller --onefile --windowed --clean --name VoxelNest voxelnest.py

完成後，執行檔位於 dist\VoxelNest.exe。

想要一鍵打包，可以建立 build.bat，內容為上面兩行指令加上 pause，之後雙擊即可。

常見問題

Q：開啟程式時出現 can't open file？

A：檔名不對或不在目前資料夾。用 dir 查看資料夾內的實際檔名，再用正確的檔名執行。

Q：防毒軟體跳出警告？

A：PyInstaller 打包的程式常被誤判，確認來源可信後選擇允許執行即可。

Q：按啟動後版本不對？

A：除了 1.8.8 外，其他版本的參數是推測值。請到 Eaglercraft 網頁點選該版本，查看網址列的 version= 後面的文字，並修改程式中 VERSIONS 的對應值後重新打包。

Q：收藏或設定不見了？

A：請確認程式是從同一個資料夾執行，設定檔 voxelnest_config.json 應存在該資料夾中。
